# Wonder Garden / Чудо-сад

В игре доступны 12 видов, шесть рецептов, три уровня грядок и питомник. Условия скрещивания и открытия видов можно посмотреть в режиме селекции и в альманахе. Технический MVP также включает Листика, автоматическую торговую лавку, декор, гармонию и журнал целей. Итоги приёмки собраны в `docs/engineering/IMPLEMENTATION_LOG.md`.

В Alpha 04 нажмите на созревшее растение в режиме «Сад», чтобы отправить урожай в инвентарь. Одноразовые растения освобождают грядку сразу. Многоразовые снова растут, пока у них есть жизни. Во вкладке «Урожай» можно продать часть партии или извлечь из неё семена. Во вкладке «Семена» выберите материал для посадки или продажи.

Для закрытого плейтеста распакуйте `Wonder_Garden_Alpha_04_Playtest.zip` и выполните `node serve-playtest.mjs` из распакованного каталога. Сервер напечатает адрес для ПК и адреса локальной сети для телефона.

## Запуск игры

Для разработки нужны Node.js 22.13+ и pnpm 11.25.0. Из корня проекта выполните:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте локальный адрес из вывода Vite. Чтобы продолжить сохранённый сад, используйте тот же браузер, хост и порт.

Проверка типов, тесты и сборка:

```sh
pnpm typecheck
pnpm test
pnpm build
```

После сборки запустите `pnpm preview`, чтобы открыть готовую игру.

Порядок первого раунда с игроками и таблица для наблюдений описаны в [сценарии плейтеста](docs/engineering/ACCEPTANCE_TESTS.md#плейтест-после-mvp).

Соберите зрелый редис, продайте часть урожая и извлеките семена из остального. Посадите клубнику и подсолнечник на соседних по стороне грядках. Соберите опылённую клубнику и извлеките семена из этой партии, чтобы получить первый гибрид. Сохранения Alpha 03 обновляются при загрузке с того же адреса. Рост идёт, пока сад открыт и вкладка видима.

Воспроизводимая проверка прогрессии — `pnpm test tests/breeding.test.ts`. Тест начинает с двух редисов, оплачивает посадки, расчистку и улучшения из выручки, восстанавливает промежуточное сохранение и высаживает все 12 видов и открывает 16 грядок.

После первой продажи откройте «Листик» под текущей целью сада. Помощник собирает урожай с самой давно созревшей грядки. При одинаковом времени созревания он выбирает меньший номер грядки. Улучшенная лавка каждые 10 игровых секунд продаёт обычный урожай, сохраняя партии для скрещивания и размножения гибридов. Проверки автоматизации запускаются командой `pnpm test tests/automation.test.ts`.

После посадки первого гибрида в режиме «Стройка» откроется декор. Выберите один из четырёх предметов и место на острове, посмотрите предпросмотр и подтвердите размещение. Купленные предметы можно переставлять и убирать в хранилище. Журнал в верхней панели показывает ранг, цели глав и текущую гармонию. Звук и экспорт сохранения доступны в настройках.

Для разработки добавьте `?debug=1` к адресу dev-сервера. Отладочная панель сохраняет отдельный сад.

## Структура проекта

| Путь | Ответственность |
|---|---|
| [src/game](src/game) | Игровая модель, правила, команды и симуляция |
| [src/persistence](src/persistence) | Проверка, миграция и хранение сохранений |
| [src/world](src/world) | Изометрия, Phaser-сцена, спрайты и ввод на острове |
| [src/ui](src/ui) | Интерфейс, панели, стили и RU/EN |
| [src/runtime](src/runtime) | Часы, звук, контракты представления и dev-панель |
| [config](config) | Баланс и геометрия острова |
| [tests](tests) и [tools](tools) | Регрессии Vitest и вспомогательная симуляция баланса |
