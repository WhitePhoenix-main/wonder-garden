# Wonder Garden · Alpha 09 — Discovery & Onboarding

Чудо-сад — браузерная игра о выращивании и селекции. Двенадцать видов дают 60 сочетаний вида и редкости. Скрещивайте соседние виды, разводите растения одного вида в теплице, управляйте урожаем с помощью Листика и выполняйте заказы. За восстановленным мостом находится Цветочная долина.

Нажмите грядку, чтобы выбрать семена, осмотреть рост, собрать урожай или убрать остатки. Рынок открывается через лавку или навигацию. Спрос меняется в активное игровое время. Цена продажи учитывает текущую котировку и производственную стоимость партии.

## Плейтест

1. Распакуйте `Wonder_Garden_Alpha_09_Playtest.zip`. Нужен Node.js 22.13 или новее.
2. Из распакованного каталога выполните `node serve-playtest.mjs`.
3. Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) или адрес локальной сети из вывода сервера на телефоне.

Сохранения хранятся в браузере. Для продолжения используйте прежний браузер, хост и порт. Схема 13 читает Alpha 08 и поддерживаемые ранние сохранения. За время отсутствия обычные посадки могут дозреть один раз, а производство питомника работает в пределах уровня теплицы.

## Новое в Alpha 09

Начните с четырёх пустых грядок и двух семян редиса. Листик покажет посадку, сбор, уборку и торговлю. Соседство по общей стороне позволяет исследовать двенадцать направленных комбинаций для шести гибридов. Альманах записывает реакции и успешные рецепты. Листик I собирает урожай, II отдельно убирает остатки, III пересаживает семена из доступного запаса.

## Первый гибрид

Посадите редис, соберите урожай, очистите грядку и продайте плоды. Из следующего урожая извлеките семена. Для первого гибрида нужны четыре изученных природных вида и шесть открытых грядок. Посадите клубнику и подсолнечник по общей стороне и извлеките семена из опылённого урожая клубники. Открытие восстанавливает теплицу. На уровне II в ней можно запустить опыт с двумя живыми экземплярами одного вида.

Настройки грядки доступны из её карточки. Листик открывается после первой продажи. Лавка III даёт переработку и резервы. Инвентарь поддерживает поиск, защиту, сравнение и массовые операции. Журнал сохраняет достижения. Условия восстановления доступны по нажатию на мост.

## Разработка

Нужны Node.js 22.13+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

В dev-сборке `?debug=1` открывает отладку с отдельным сохранением. `node tools/simulate-alpha09.mjs` сравнивает производственные стратегии, проходы по видам и работу питомника.

| Путь | Ответственность |
|---|---|
| `src/game/` | Состояние, команды, генетика, торговля и симуляция |
| `src/persistence/` | Валидация, миграция, резервная копия |
| `src/world/`, `src/ui/` | Phaser, камеры, ввод и DOM-интерфейс RU/EN |
| `src/runtime/` | Игровые часы, звук, контракты представления |
| `config/` | Баланс и карты двух территорий |
| `tests/`, `tools/` | Регрессии, браузерные сценарии и симуляция |
