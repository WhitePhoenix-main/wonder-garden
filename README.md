# Wonder Garden · Alpha 08 — Living Garden

Чудо-сад — браузерная игра о выращивании и селекции. Двенадцать видов дают 60 сочетаний вида и редкости. Скрещивайте соседние виды, разводите растения одного вида в теплице, управляйте урожаем с помощью Листика и выполняйте заказы. За восстановленным мостом находится Цветочная долина.

Нажмите грядку, чтобы выбрать семена, осмотреть рост, собрать урожай или убрать остатки. Рынок открывается через лавку или навигацию. Спрос меняется в активное игровое время. Цена продажи учитывает текущую котировку и производственную стоимость партии.

## Плейтест

1. Распакуйте `Wonder_Garden_Alpha_08_Playtest.zip`. Нужен Node.js 22.13 или новее.
2. Из распакованного каталога выполните `node serve-playtest.mjs`.
3. Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) или адрес локальной сети из вывода сервера на телефоне.

Сохранения хранятся в браузере. Для продолжения используйте прежний браузер, хост и порт. Схема 12 читает Alpha 07 и более ранние сохранения. За время отсутствия обычные посадки могут дозреть один раз, а производство питомника работает в пределах уровня теплицы.

## Новое в Alpha 08

Последняя жизнь оставляет засохшее растение. Листик может убирать остатки, а с III уровня пересаживает доступные семена. Альманах показывает требования тиров и этапы гибридных исследований. Теплица II открывает две производственные грядки, III — семенное производство и клонирование, IV — оптовую продажу.

## Первый гибрид

Соберите редис, уберите его остатки и продайте часть плодов. Из оставшихся извлеките семена. Для первого гибрида нужны четыре изученных природных вида и шесть открытых грядок. Посадите клубнику и подсолнечник по общей стороне и извлеките семена из опылённого урожая клубники. Первая удача открывает питомник. В теплице II два живых экземпляра одного вида дают внутривидовой опыт.

Настройки грядки доступны из её карточки. Листик открывается после первой продажи. Лавка III даёт переработку и резервы. Инвентарь поддерживает поиск, защиту, сравнение и массовые операции. Журнал сохраняет достижения. Условия восстановления доступны по нажатию на мост.

## Разработка

Нужны Node.js 22.13+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

В dev-сборке `?debug=1` открывает отладку с отдельным сохранением. Production не содержит этой панели. `node tools/simulate-alpha08.mjs` сравнивает производственные стратегии, проходы по видам и работу питомника.

| Путь | Ответственность |
|---|---|
| `src/game/` | Состояние, команды, генетика, торговля и симуляция |
| `src/persistence/` | Валидация, миграция, резервная копия |
| `src/world/`, `src/ui/` | Phaser, камеры, ввод и DOM-интерфейс RU/EN |
| `src/runtime/` | Игровые часы, звук, контракты представления |
| `config/` | Баланс и карты двух территорий |
| `tests/`, `tools/` | Регрессии, браузерные сценарии и симуляция |
