# Wonder Garden / Чудо-сад

В игре доступны 12 видов, шесть рецептов, три уровня грядок и питомник. Условия скрещивания и открытия видов можно посмотреть в режиме селекции и в коллекции. Технический MVP также включает Листика, автоматическую торговую лавку, декор, гармонию и журнал целей. Итоги приёмки собраны в `docs/engineering/IMPLEMENTATION_LOG.md`.

## Запуск игры

Для разработки нужны Node.js 22.13+ и pnpm 11.25.0. Из корня проекта выполните:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте локальный адрес из вывода Vite. Чтобы продолжить сохранённый сад, используйте тот же браузер, хост и порт.

Проверка типов, тесты и сборка:

```sh
pnpm typecheck
pnpm test
pnpm build
```

После сборки запустите `pnpm preview`, чтобы открыть готовую игру.

Порядок первого раунда с игроками и таблица для наблюдений описаны в [сценарии плейтеста](docs/engineering/ACCEPTANCE_TESTS.md#плейтест-после-mvp).

Соберите зрелый редис, продайте урожай и накопите на клубнику. Посадите подсолнечник на соседнюю по стороне грядку и трижды соберите клубнику, чтобы получить первое гибридное семя. Игра сохраняется в этом браузере; рост продолжается, пока вкладка видима.

Отдельная проверка второго спринта — `pnpm test tests/breeding.test.ts`. Тест начинает с двух редисов, оплачивает посадки, расчистку и улучшения из выручки, восстанавливает промежуточное сохранение и выращивает все 12 видов до урожая.

После первой продажи откройте «Листик» под текущей целью сада. Помощник собирает по одному плоду с самой давно созревшей грядки. При одинаковом времени созревания он выбирает меньший номер грядки. После найма через эту панель или корзину можно улучшить лавку: она продаёт урожай каждые 10 игровых секунд и сразу при заполнении корзины. Ручной сбор и продажа остаются доступны. Проверки автоматизации запускаются командой `pnpm test tests/automation.test.ts`.

После посадки первого гибрида в режиме «Стройка» откроется декор. Выберите один из четырёх предметов и место на острове, посмотрите предпросмотр и подтвердите размещение. Купленные предметы можно переставлять и убирать в хранилище. Журнал в верхней панели показывает ранг, цели глав и текущую гармонию. Звук и экспорт сохранения доступны в настройках.

Для разработки добавьте `?debug=1` к адресу dev-сервера. Отладочная панель сохраняет отдельный сад.

## Структура проекта

| Путь | Ответственность |
|---|---|
| [src/game](src/game) | Игровая модель, правила, команды и симуляция |
| [src/persistence](src/persistence) | Проверка, миграция и хранение сохранений |
| [src/world](src/world) | Изометрия, Phaser-сцена, спрайты и ввод на острове |
| [src/ui](src/ui) | Интерфейс, панели, стили и RU/EN |
| [src/runtime](src/runtime) | Часы, звук, контракты представления и dev-панель |
| [config](config) | Баланс и геометрия острова |
| [tests](tests) и [tools](tools) | Регрессии Vitest и вспомогательная симуляция баланса |
