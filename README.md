# Wonder Garden · Alpha 05 — Garden Evolution

Чудо-сад — браузерная игра о выращивании и селекции. Двенадцать видов дают 60 сочетаний вида и редкости. Скрещивайте соседние виды, разводите растения одного вида в теплице, управляйте урожаем с помощью Листика и выполняйте заказы. За восстановленным мостом находится Цветочная долина.

## Плейтест

1. Распакуйте `Wonder_Garden_Alpha_05_Playtest.zip`. Нужен Node.js 22.13 или новее.
2. Из распакованного каталога выполните `node serve-playtest.mjs`.
3. Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) или адрес локальной сети из вывода сервера на телефоне.

Сохранения хранятся в браузере. Для продолжения используйте прежний браузер, хост и порт. Схема 9 читает существующие сохранения Alpha 04 и ранних альф. Активное время останавливается вместе с игрой и при скрытии вкладки.

## Первый гибрид

Соберите редис нажатием на зрелую грядку. Продайте часть плодов и извлеките семена из оставшихся. Посадите клубнику рядом с подсолнечником и извлеките семена из опылённого урожая клубники. Первый успешный опыт открывает питомник. Улучшите теплицу до II через «Развитие», поместите в питомник два живых экземпляра одного вида и начните внутривидовой опыт.

Режимы регулировки грядок доступны в карточке грядки. Листик открывается после первой продажи, лавка III позволяет настроить переработку и резервы. Инвентарь поддерживает поиск, защиту, сравнение и массовые операции. Журнал сохраняет достижения. Условия открытия моста показаны в панели «Развитие».

## Разработка

Нужны Node.js 22.13+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

В dev-сборке `?debug=1` открывает отладку с отдельным сохранением. Production не содержит этой панели. `node tools/simulate-alpha05.mjs 120` запускает воспроизводимую модель экономики.

| Путь | Ответственность |
|---|---|
| `src/game/` | Состояние, команды, генетика, торговля и симуляция |
| `src/persistence/` | Валидация, миграция, резервная копия |
| `src/world/`, `src/ui/` | Phaser, камеры, ввод и DOM-интерфейс RU/EN |
| `src/runtime/` | Игровые часы, звук, контракты представления |
| `config/` | Баланс и карты двух территорий |
| `tests/`, `tools/` | Регрессии, браузерные сценарии и симуляция |

Правила и текущая приёмка описаны в [спецификации](docs/design/ALPHA05_SPEC.md), [архитектуре](docs/engineering/ARCHITECTURE.md), [отчёте QA](docs/engineering/ALPHA05_QA_REPORT.md) и [замерах баланса](docs/engineering/ALPHA05_BALANCE.md). История обновлений находится в [CHANGELOG](CHANGELOG.md).
