# Alpha 09 · Интерфейс

- Сад сохраняет изометрический масштабируемый вид и контекстные действия. Обычный клик выбирает пустую грядку, собирает созревшее растение или убирает засохшее. Карточка живого растения показывает оставшиеся сборы и сигналы опыления.
- Подсветка обучающей цели использует координаты DOM или проекцию грядки Phaser. При изменении геометрии она следует за элементом. Для недоступной цели управление восстанавливается. Уменьшенная анимация поддерживается установленным предпочтением браузера.
- При конфликте в карточке растения появляются направления. Названия неизвестных результатов скрыты. Зафиксированное опыление отображается после выбора.
- Альманах отображает каталог, требования, исследованные реакции и уже успешные рецепты. Матрица использует изученные виды. Сочетания с несколькими донорами представлены карточками.
- Первое полученное семя гибрида открывает окно открытия. Посадка добавляет вид в каталог и продвигает коллекцию. Уведомления о генетике короче окна открытия.
- В отчёте возвращения указаны время отсутствия и фактическое время работы питомника. Остальные показатели включают урожай, семена, монеты, затраченный запас, созревшие посадки и оплаченные эксперименты.
