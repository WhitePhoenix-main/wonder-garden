# Согласование решений

## Alpha 05

| Тема | Принято |
|---|---|
| Геном | Канонический массив в `plus`, одна строка или `null` в мигрируемых записях. Прежние неактивные черты видны и не копируются. |
| Родословная | История опытов хранит ID и профили родителей. Идентичные семена остаются в одной стопке. |
| Наследование | Учитывается допустимость для вида. При несовместимом родительском недостатке выбирается допустимая замена. |
| Оплата | Опыты фиксируют исход при запуске. Массовый инвентарь применяет операции к временной копии. Заказы резервируют общий объём предметов между строками и списывают один раз. |
| Цена | Производственная цена неизменна после сбора, округление принадлежит партии. Рыночный коэффициент Alpha 05 равен 1. |
| Автоматизация | Сбор → переработка → пересадка → периодическая продажа. После достижения цели семенной урожай можно продавать при включённых продажах урожая и семян. |
| Долина | Геометрия первого острова и его индексы сохранены. Долина добавляет 8 индексов и 6 слотов декора. Гармония открывает мост и небольшой бонус к росту. |
| Коллекция | Комбинации из живых экземпляров восстанавливаются при миграции. Известные виды сохраняются. Семена в инвентаре не подтверждают факт посадки. |

Секции ниже описывают правила выпущенных ранее версий.

## Alpha 04

| Тема | Решение |
|---|---|
| Сбор | Одно нажатие в режиме сада. Урожай остаётся в инвентаре до явной операции или такта лавки. |
| Растения | Четыре одноразовых вида, восемь многоразовых. Признаки жизней продолжают действовать у многоразовых. |
| Опыление | Снимок фиксируется за цикл. При нескольких подходящих рецептах приоритет у неизученного. Солнечная клубника передаёт профиль орхидее, Медовый клевер входит в условия. |
| Извлечение | Бюджет собственных семян и одна возможная попытка скрещивания относятся к исходной порции сбора. При частичной обработке остаток сохраняется. |
| Лавка | Продажа каждые 10 игровых секунд. Резервы гибридов, партии с неиспользованными попытками и урожай с признаками сохраняются при автопродаже. |
| Миграция | Схема 8. Старый урожай сохраняет вид, объём и цену. Для его карточек доступна продажа, поскольку прежний формат хранил только вид и цену. |

## Решения v1.0 и предыдущих альф

Этот документ фиксирует изменения относительно исходного `04_wonder_garden.md` и разрешение неоднозначностей из обсуждения. Решения, добавленные для инженерной определённости, не следует считать проверенными на игроках или отдельным подтверждением пользователя.

| Тема | Принято v1.0 | Причина |
|---|---|---|
| Масштаб | 12/6 видов/рецептов, 20–30 мин | Вместо прежних 6/2 и 15 мин; развитие селекции |
| Мир | 10×8, посадки 4×4, 4 открыты | Разделить ландшафт и производственную сетку |
| Расширение | По одной соседней клетке | Вместо групп по 4; контроль конфигурации |
| Апгрейд | Три уровня отдельных грядок | Вместо глобальных +% и раннего предложения 4 уровней |
| Гибриды | Семенной сбор с выбранным донором, повторные опыты, наследование | Вместо покупки гибридов после открытия |
| Цена урожая | Фиксировать на сборе, округлять итог продажи | Не менять цены уже собранных предметов при перестановке |
| Рецепты | Список GDD/JSON | Предыдущая схема ветвей местами была иллюстративной; таблица рецептов приоритетна |
| Родители | Не требуют зрелости, ауры активны с посадки | Простота и предсказуемость |
| Удаление | Лопата после первой продажи, компост с подтверждением. Питомник открывает первый рецепт | Защита редких видов; аварийный редис только при безвыходном состоянии |
| Заполненный остров | До первого рецепта при 16/16 занятых разрешена подтверждённая замена посадкой по обычной цене; старое растение хранится со своим прогрессом | Позволяет создать соседнюю пару родителей даже после посадки 16 редисов; досрочное хранение отдельной командой закрыто |
| Сроки | Целевые, не фактические | Ранее приводились числа симуляции без воспроизводимого скрипта; не использовать как доказанные |
| Автоматизация | Листик доступен после первой продажи, 5/2/1 сек, автопродажа после найма | Уточнение раннего открытия без жёсткого тайм-гейта |
| Таймеры | Сброс при найме/апгрейде, при любой продаже; нет накопления действий | Новая инженерная договорённость |
| Питомник | Неограничен, readySince при возврате обнулён до текущего игрового времени | Исключить приоритет за период хранения |
| Декор | Четыре слота, четыре типа, повторные покупки допустимы без повторной гармонии | Ограниченный редактор, творческая свобода |
| Гармония | 225 растения +35 декор +50 постройки = 310 max; только размещённое | Стартовая лавка не даёт +25 до апгрейда; показатель текущий |
| Завершение | 12 когда-либо посаженных и 16 открытых | Не требовать всех посадок одновременно, гармонии или апгрейдов |
| Острова | Только первый, карта и мост-покупка после MVP | Ранние предложения второго острова — релизное видение |
| Обучение Alpha 03 | Первый выбранный солнечный опыт гарантирован. Посадка гибрида, питомник и отложенная посадка доступны из результата | Правила работают при пропуске подсказок и загрузке сада |
| Вход и звук Alpha 02 | Меню при запуске и пауза при возврате. Вход в сад запускает оригинальную восьмитактовую тему. Музыка и эффекты переключаются отдельно | Управление временем и звуком у игрока |
| Офлайн | Нет в MVP | Сначала проверить active gameplay |
| Сумма бюджета | 25640 без семян/декора | Исправляет прежние 27340; суммы из конфига |
| Арт | №2+№3, модульные спрайты, 128×64 | Выбранное направление, не утверждённый финальный комплект |
| Стек | Phaser 3 + TypeScript strict + Vite + DOM UI | Без React/backend/SDK, версия зависимостей выбирается при разработке |

Открытые риски: ручной перенос ауры перед каждым сбором может оказаться выгодной рутиной; производительность III Листика недостаточна для многих быстрых посадок; детерминированная селекция может стать слишком простой; реальная длительность и читаемость mobile неизвестны; генерация не гарантирует согласованные тайлы. Проверять на прототипе. Не компенсировать риски дополнительными механиками заранее.
