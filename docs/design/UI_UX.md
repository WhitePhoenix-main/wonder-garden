# UI/UX · Wonder Garden

## Рынок Alpha 06

Рынок открывается из инвентаря и «Развития». После первой продажи панель показывает время до расчёта котировок. Урожай и семена переключаются вкладками. По каждому изученному виду видны спрос, насыщение и актуальный множитель. Стрелки и проценты поясняют направление цены. Инвентарь сортирует по текущей цене и показывает сумму выбранного объёма. Знакомые действия продажи остаются доступны на обоих viewport.

Игра открывается в меню на фоне острова. Вход в сад запускает игровые часы и музыку. В меню доступны язык, отдельные переключатели музыки и эффектов, продолжение и подтверждённая новая игра. Над растением показан остаток цикла, на переднем крае грядки — её уровень.

## Компоновка
Desktop 1366×768: canvas занимает рабочую область; сверху монеты, корзина и стоимость продажи, альманах, журнал, настройки; снизу четыре режима (Сад, Посадка, Селекция, Строительство); справа контекстная панель шириной ориентировочно 300–340 CSS px, скрывается без выбора; слева небольшая цель и камера. Помощник доступен через значок после первой продажи. Питомник через теплицу; продажа через корзину/лавку. Не перекрывать выбранную клетку: camera focus с учётом размера панели.

Mobile 390×844: верхний HUD в 1–2 рядах, кнопка продажи всегда доступна, фиксированная нижняя навигация с короткими метками и safe area. Контекстная панель — bottom sheet с закрытием/сворачиванием, каталог и книга прокручиваются внутри; не прокручивать страницу жестом на canvas. На телефоне не пытаться вместить весь остров так, чтобы грядки нельзя было выбрать. Zoom/pan и кнопка центрирования. Проверить горизонтальную мобильную ориентацию, узкие экраны, длинные русские подписи, safe-area-inset. Кнопки ≥44 CSS px, явные focus styles, доступные имена, текстовые состояния вместе с цветами. Минимум декора интерфейса; не использовать текст, запечённый в картинках.

## Режимы и панель
| Режим | Тап по грядке | Жест по грядкам | Отображение |
|---|---|---|---|
| Сад | Созревшее растение собирается сразу. У растущего открывается карточка | Лопата выбирает цель. Свайп перемещает камеру | Знак зрелости, количество полученного урожая, таймер повторного роста |
| Посадка | После выбора вида — посадка на доступную цель; без вида — сведения | Нет сбора | Свободные места зелёным, доступность семян |
| Селекция | Выбор экземпляра, список рецептов/аур | Нет сбора | Фиолетовые связи только выбранного, условия, прогресс |
| Строительство | Расчистка / грядка / инструмент перемещения или декора | Нет сбора | Доступные клетки, цены, уровень, preview |

Один активный режим, один контекст выбора. Смена режима отменяет незавершённый выбор, но не выполненные команды. Отмена/закрытие никогда не тратит деньги. Панели не останавливают симуляцию; при скрытии вкладки она останавливается. При открытом подтверждении заблокировать проход событий к миру, при закрытии вернуть фокус. Не блокировать игру серией уведомлений: очередь новых открытий, короткий toast и возможность открыть карточку; если используется одно окно открытия, оно не должно навечно блокировать UI.

## Ввод и камера
Pointer events: запомнить origin при pointerdown. В саду жест с грядки — выбор грядки, со свободного фона — pan; минимальный порог движения, при тапе определить действие один раз. При переходе через клетку собрать её максимум один раз за жест; использовать пересечение траектории с клетками, а не только конечную точку. Для камеры в любом режиме доступен drag фона; колесо мыши/щипок — zoom вокруг центра жеста, два пальца отменяют harvest drag и выбор покупки. На pointerup, pointercancel, blur, visibilitychange очистить активный жест и capture. UI события не попадают на canvas. Не покупать участок жестом: явная кнопка подтверждения. Для мобильных: не требовать hover; подсказка появляется по тапу. Опциональный drag объектов — после MVP, основной способ — источник → цель.

## Сценарии

Инвентарь открывается из HUD. Вкладки «Урожай» и «Семена» используют отдельные карточки партий. Кнопки количества меняют итог сделки и предпросмотр выхода. Подробности урожая показывают профили родителей. Подробности семян показывают выход, жизни и повторный рост. Подтверждение используется при продаже последнего посадочного резерва или селекционного урожая. На мобильном инвентарь занимает широкую нижнюю панель, элементы камеры скрываются, пока эта панель открыта.
| Сценарий | Действия | Обратная связь |
|---|---|---|
| Сбор | Выбрать зрелое растение и тип сбора | Плоды в корзину или семена в запас, списание одной жизни |
| Продажа | Нажать «Продать N» | Начисление монет, корзина очищена; кнопка disabled при пустой |
| Посадка базового | Посадка → вид → свободная грядка | Списать цену на успешной команде; росток; карточка выбранного вида |
| Посадка гибрида | Вид с доступным семенем → грядка | Списать одно семя, изучение нового вида |
| Замена | Выбор семени → занятая клетка → подтвердить хранение старого | После открытия питомника либо когда заняты все 16 мест; все или ничего |
| Расчистка | Стройка → доступный участок → цена/подтвердить | Убрать камни/пень/траву, появление земли |
| Апгрейд | Стройка → грядка → сравнение/улучшить | Стоимость, уровень, новая скорость/цена; без сброса роста |
| Перемещение | Стройка → переместить → источник → цель | Подсветка допустимых целей, обмен или перенос, пересчёт аур |
| Хранение | Теплица/карточка растения → в питомник | Перенос состояния растения, освободить грядку |
| Возврат | Питомник → экземпляр → свободная грядка | Прежнее состояние, обновление аур |
| Селекция | Режим → растение/рецепт | Подсветка, чек-лист условий, счётчик, где найти родителя |
| Открытие | Уведомление → посадить гибрид / открыть питомник / позже | Новое семя, имя/силуэт/свойства; альманах после посадки |
| Помощник | Значок → нанять/улучшить | Интервал, стоимость, статус: собирает/ждёт/корзина полна |
| Автопродажа | Лавка/корзина → приобрести | Понятная цена и требования; автоматизация постоянно активна |
| Декор | Стройка → декор → слот → preview/подтвердить | Стоимость, гармония, сохранённый экземпляр |
| Журнал | HUD → главы | Цели автоматически отмечаются; необязательны |
| Настройки | HUD → звук, язык, центрирование, сброс | Сброс требует явного подтверждения; сообщение об ошибке сохранения |

## Состояния
Каталог отдельно показывает покупку базового семени и посадку вариантов из запаса. Альманах содержит портреты, статус, тир, шкалы роста, доходности и гармонии, исходные диапазоны и рецепты. Карточка грядки показывает свойства экземпляра и длительность цикла с текущими модификаторами. Питомник открывается через теплицу и кнопку в HUD.

Стройка: закрыто/соседство/доступно/нет денег/выбрано/предпросмотр. Грядка: пустая/растёт/готова; уровень и цена следующего перехода, если III — максимум. Селекция: нет родителей/не хватает уровня/активно/приостановлено/раскрыто. Не полагаться только на цвета: зелёный + стрелка роста, золото + монета для цены, фиолетовый + пунктир для скрещивания, числовые счётчики. В обычном саду эффект лёгкий, подробности только при выборе.

## Обучение
Первый урожай → продать → посадить клубнику → показать соседство с подсолнечником → первый рецепт → теплица и посадка гибрида. Подсказки по событиям (GDD), можно закрыть/пропустить, действия доступны независимо от пропуска. Не блокировать интерфейс учебными оверлеями. Если игрок сделал действие заранее, не заставлять повторять. Книга и журнал доступны с начала. После первого гибрида панель «Развитие» ведёт к селекции, заказам и территориям.

## Стиль
Пергаментные панели, тонкие рамки, дерево только как акцент; основные числа контрастны. RU/EN через словари, реальные кнопки/текст HTML. Арт — локальные иконки/орнаменты, не полноэкранные изображения. При reduced-motion уменьшить частицы и отключить декоративное покачивание. Критерии приёмки — ACCEPTANCE_TESTS.

## Развитие и производство Alpha 05

«Развитие» собирает карту территорий, Селекционную теплицу, Торговую лавку и доску заказов. Карта показывает доступные территории и прогресс ремонта моста. Переход закрывает панель и восстанавливает масштаб и положение камеры выбранного острова. Мобильная панель «Развитие» содержит прямой вход в «Листик и автоматизация».

В теплице игрок выбирает два экземпляра одного вида, видит их признаки и вероятности пяти редкостей. Список опытов показывает оставшееся активное время или кнопку получения семени. Теплица III показывает историю с профилями родителей. В карточках заказов отображаются условия, доступные партии и награда.

Инвентарь поддерживает поиск, фильтр по виду, тиру, редкости и признакам, избранное, сравнение двух профилей одного вида и выбор количества для нескольких партий. Массовое действие показывает число операций, прогноз и исключения. Выбор грядки открывает назначение, приоритет, режим сбора, целевой запас и профиль пересадки. Редкость показывается текстом и маркером. Альманах хранит матрицу 12×5, журнал — восьмиступенчатый ранг и постоянные достижения.
