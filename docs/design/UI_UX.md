# UI/UX — один сад, четыре режима

Игра открывается в меню на фоне острова. Вход в сад запускает игровые часы и музыку. В меню доступны язык, отдельные переключатели музыки и эффектов, продолжение и подтверждённая новая игра. Над растением показан остаток цикла, на переднем крае грядки — её уровень.

## Компоновка
Desktop 1366×768: canvas занимает рабочую область; сверху монеты, корзина и стоимость продажи, коллекция, журнал, настройки; снизу четыре режима (Сад, Посадка, Селекция, Строительство); справа контекстная панель шириной ориентировочно 300–340 CSS px, скрывается без выбора; слева небольшая цель и камера. Помощник доступен через значок после первой продажи. Питомник через теплицу; продажа через корзину/лавку. Не перекрывать выбранную клетку: camera focus с учётом размера панели.

Mobile 390×844: верхний HUD в 1–2 рядах, кнопка продажи всегда доступна, фиксированная нижняя навигация с короткими метками и safe area. Контекстная панель — bottom sheet с закрытием/сворачиванием, каталог и книга прокручиваются внутри; не прокручивать страницу жестом на canvas. На телефоне не пытаться вместить весь остров так, чтобы грядки нельзя было выбрать. Zoom/pan и кнопка центрирования. Проверить горизонтальную мобильную ориентацию, узкие экраны, длинные русские подписи, safe-area-inset. Кнопки ≥44 CSS px, явные focus styles, доступные имена, текстовые состояния вместе с цветами. Минимум декора интерфейса; не использовать текст, запечённый в картинках.

## Режимы и панель
| Режим | Тап по грядке | Жест по грядкам | Отображение |
|---|---|---|---|
| Сад | Сбор готового; если не готова — короткая карточка | Массовый сбор готового. С лопатой тап выбирает цель, свайп перемещает камеру | Плоды, мягкие эффекты, без постоянных цен/полос |
| Посадка | После выбора вида — посадка на доступную цель; без вида — сведения | Нет сбора | Свободные места зелёным, доступность семян |
| Селекция | Выбор экземпляра, список рецептов/аур | Нет сбора | Фиолетовые связи только выбранного, условия, прогресс |
| Строительство | Расчистка / грядка / инструмент перемещения или декора | Нет сбора | Доступные клетки, цены, уровень, preview |

Один активный режим, один контекст выбора. Смена режима отменяет незавершённый выбор, но не выполненные команды. Отмена/закрытие никогда не тратит деньги. Панели не останавливают симуляцию; при скрытии вкладки она останавливается. При открытом подтверждении заблокировать проход событий к миру, при закрытии вернуть фокус. Не блокировать игру серией уведомлений: очередь новых открытий, короткий toast и возможность открыть карточку; если используется одно окно открытия, оно не должно навечно блокировать UI.

## Ввод и камера
Pointer events: запомнить origin при pointerdown. В саду жест с грядки — harvest drag, со свободного фона — pan; минимальный порог движения, при тапе определить действие один раз. При переходе через клетку собрать её максимум один раз за жест; использовать пересечение траектории с клетками, а не только конечную точку. Для камеры в любом режиме доступен drag фона; колесо мыши/щипок — zoom вокруг центра жеста, два пальца отменяют harvest drag и выбор покупки. На pointerup, pointercancel, blur, visibilitychange очистить активный жест и capture. UI события не попадают на canvas. Не покупать участок жестом: явная кнопка подтверждения. Для мобильных: не требовать hover; подсказка появляется по тапу. Опциональный drag объектов — после MVP, основной способ — источник → цель.

## Сценарии
| Сценарий | Действия | Обратная связь |
|---|---|---|
| Сбор | Тап зрелого растения / провести по грядкам | Плод в корзину, короткий звук, прогресс цикла |
| Продажа | Нажать «Продать N» | Начисление монет, корзина очищена; кнопка disabled при пустой |
| Посадка базового | Посадка → вид → свободная грядка | Списать цену на успешной команде; росток; карточка выбранного вида |
| Посадка гибрида | Вид с доступным семенем → грядка | Списать одно семя, изучение нового вида |
| Замена | Выбор семени → занятая клетка → подтвердить хранение старого | После открытия питомника либо когда заняты все 16 мест; все или ничего |
| Расчистка | Стройка → доступный участок → цена/подтвердить | Убрать камни/пень/траву, появление земли |
| Апгрейд | Стройка → грядка → сравнение/улучшить | Стоимость, уровень, новая скорость/цена; без сброса роста |
| Перемещение | Стройка → переместить → источник → цель | Подсветка допустимых целей, обмен или перенос, пересчёт аур |
| Хранение | Теплица/карточка растения → в питомник | Перенос состояния растения, освободить грядку |
| Возврат | Питомник → экземпляр → свободная грядка | Прежнее состояние, обновление аур |
| Селекция | Режим → растение/рецепт | Подсветка, чек-лист условий, счётчик, где найти родителя |
| Открытие | Уведомление → карточка → посадить/позже | Новое семя, имя/силуэт/свойства; коллекция после посадки |
| Помощник | Значок → нанять/улучшить | Интервал, стоимость, статус: собирает/ждёт/корзина полна |
| Автопродажа | Лавка/корзина → приобрести | Понятная цена и требования; автоматизация постоянно активна |
| Декор | Стройка → декор → слот → preview/подтвердить | Стоимость, гармония, сохранённый экземпляр |
| Журнал | HUD → главы | Цели автоматически отмечаются; необязательны |
| Настройки | HUD → звук, язык, центрирование, сброс | Сброс требует явного подтверждения; сообщение об ошибке сохранения |

## Состояния
Каталог семян: неизвестно/условие открытия, доступно с ценой, недоступно из-за денег, гибрид с количеством, гибрид без семян. Не смешивать купленный экземпляр и семена. Энциклопедия: фильтры все/базовые/гибриды, карточки неизвестно/рецепт открыт/изучено; подробности, происхождение, ауры и размножение. Питомник: вкладки Семена, Растения, Эксперименты; показать ID/тип, готовность, прогресс, действия. Пустые состояния объясняют следующий шаг.

Стройка: закрыто/соседство/доступно/нет денег/выбрано/предпросмотр. Грядка: пустая/растёт/готова; уровень и цена следующего перехода, если III — максимум. Селекция: нет родителей/не хватает уровня/активно/приостановлено/раскрыто. Не полагаться только на цвета: зелёный + стрелка роста, золото + монета для цены, фиолетовый + пунктир для скрещивания, числовые счётчики. В обычном саду эффект лёгкий, подробности только при выборе.

## Обучение
Первый урожай → продать → посадить клубнику → показать соседство с подсолнечником → первый рецепт → теплица и посадка гибрида. Подсказки по событиям (GDD), можно закрыть/пропустить, действия доступны независимо от пропуска. Не блокировать интерфейс учебными оверлеями. Если игрок сделал действие заранее, не заставлять повторять. Книга и журнал доступны с начала. Не показывать рабочую карту островов в MVP.

## Стиль
Пергаментные панели, тонкие рамки, дерево только как акцент; основные числа контрастны. RU/EN через словари, реальные кнопки/текст HTML. Арт — локальные иконки/орнаменты, не полноэкранные изображения. При reduced-motion уменьшить частицы и отключить декоративное покачивание. Критерии приёмки — ACCEPTANCE_TESTS.
