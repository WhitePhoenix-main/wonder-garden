# Alpha 09 · Обучение

| Шаг | Условие перехода | Цель подсветки |
|---|---|---|
| Приветствие | Игрок подтверждает готовность | Карточка Листика |
| Первое семя | В саду появилось растение | Свободная грядка, затем семя из запаса |
| Рост и первый сбор | Успешно получены плоды | Созревшее растение. Пока оно растёт, подсказка оставляет управление доступным |
| Запас сборов и уборка | Засохшее растение убрано | Грядка с засохшим растением |
| Первая продажа | Принята продажа | Рынок и сумма продажи партии |
| Второй посев | В саду снова есть живая посадка | Пустая грядка и оставшееся семя |
| Второй урожай | Получена партия для переработки | Созревшая посадка |
| Извлечение | Семена успешно извлечены | Партия урожая в инвентаре |

Если после первой продажи в корзине остались подходящие плоды, извлечение доступно сразу. Подсказки учитывают текущие посадки и совершённые команды. Пропуск доступен из активной карточки, повтор — в настройках. Повтор восстанавливает подсказки без сброса выращенного сада.

Первая ботаническая глава объясняет условия тира II, мать и донора, соседство по общей стороне, опылённую партию и посадку нового вида. Основная комбинация клубники с подсолнечником гарантирует первую Солнечную клубнику. Дальше подсказки реагируют на состояние рынка, сада, генетических коллекций, теплицы и Листика. В окне возврата отдельно показана офлайн-выработка.
