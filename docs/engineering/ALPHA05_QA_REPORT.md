## Что выявили проверки

- Мобильный CSS скрывал единственный вход к Листику. Панель «Развитие» теперь содержит доступную кнопку. На узком экране название территории помещается рядом с навигацией. Готовое растение можно защитить из «Стройки», живой экземпляр в хранилище — из питомника.
- При достижении семенного запаса переработка останавливалась и корзина заполнялась. При разрешённой продаже урожая и семян лавка теперь освобождает незащищённый неопылённый избыток. Добавлена регрессия на 600 активных секунд.
- Профиль можно разблокировать из карточки урожая, даже если его нет в запасе семян.
- План заказа раньше мог засчитать две последние партии гибрида как взаимные источники. Планировщик перепроверяет источник после каждого списания. Исчерпанная семенная квота не считается запасом.
- Интервалы, защиту профиля и единственную выдачу результата проверили до и после сохранения. Отладочный интерфейс отсутствовал при `?debug=1` в production.

## Ограничения

Мобильный прогон использует эмуляцию касаний. Физические телефоны, длинные людские сессии и восприятие временной графики требуют отдельного плейтеста. Браузерные механики середины игры проверяются с подготовленного снимка. Полный легальный путь до моста и Legendary проверен через модель и команды. Достижимость всех 60 сочетаний проверена воспроизводимым наследованием для каждого вида.

В пассивной смешанной планировке сохранённые селекционные партии могут заполнить корзину. Явная переработка освобождает место. Баланс длительных опытов, отдача уровней грядок IV–V и стоимость заказов остаются задачами Alpha 06. Основной JS-чанк 1 682,59 КБ, 410,18 КБ gzip. Vite сообщает о превышении порога 500 КБ.
