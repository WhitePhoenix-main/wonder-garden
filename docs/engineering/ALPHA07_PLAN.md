# План Alpha 07

Рабочая ветка `codex/alpha-07` основана на `origin/main` в коммите `725f5c36`. Исходное рабочее дерево было на `6a7afd1`. Существующий незарегистрированный архив Alpha 03 сохранён. Для базовых проверок использована изолированная копия дерева merge-коммита с установленными зависимостями.

Генетика владеет правилами наследования, теплицей и сериями экспериментов. Экономика владеет рынком, планировщиком заказов, политиками и их симуляцией. Интеграция объединяет общие команды, валидацию старых схем, DOM, учёт сессии, сборку и сценарии приёмки. Независимый браузерный проход проверяет новые механики на собранном клиенте.
