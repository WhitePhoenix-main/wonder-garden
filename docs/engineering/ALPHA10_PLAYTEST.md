# Alpha 10 · Независимый плейтест

Распакуйте `Wonder_Garden_Alpha_10_Playtest.zip` и запустите `node serve-playtest.mjs` с Node.js 22.13+. Введите адрес из вывода сервера. Выделите отдельный браузерный профиль для чистого старта. Для проверки совместимости используйте знакомый адрес, порт и сохранение Alpha 09.

1. Дайте участнику посадить, собрать, продать и извлечь первые семена. Зафиксируйте, понятно ли, чем серия посева отличается от обычной посадки.
2. После первого гибрида предложите попробовать чернику с лунным цветком. Попросите объяснить выбор резонанса и что изменится, если выбрать другой донорский экземпляр.
3. Через 30–45 минут повторно измерьте действия в минуту. Отмечайте отдельно касания, жесты, открытие окон, осмысленные решения, автоматические операции и паузы без понятной цели.
4. На телефоне испытайте портрет, альбом, серию посадки, панорамирование и выход из подсказки. Сравните короткое возвращение к питомнику с активным уходом.
5. Для длинной сессии запишите время до трёх последних вех и способ накопления на мост. Отдельно соберите причины, по которым участник отложил селекцию или автоматизацию.

После наблюдений оцените, какая часть сокращения действий пришлась на новый интерфейс, а какая — на удобные стратегии. Для следующей итерации сначала устраните повторяющиеся затруднения с видимостью целей, расходом семян и содержанием финальных минут.
