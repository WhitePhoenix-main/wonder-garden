# Alpha 08 · Техническая приёмка

Версия 0.8.0, ветка `codex/alpha-08`, базовый коммит `9f11c96`. Архив содержит `dist/`, `serve-playtest.mjs` и `START.txt`. Размер 441 680 байт.

```text
SHA-256 d2c0b22b80fff6b81946def3e22f43b004d4702e39115996c230e7154df482cf
```

После распаковки хеш каждого файла клиента совпал с соответствующим файлом production-сборки. Локальный сервер запущен из распакованного каталога.

## Модель и команды

- Исходные `pnpm typecheck`, `pnpm test` и `pnpm build` для Alpha 07 прошли. Пройдено 129 тестов в 19 наборах.
- Для Alpha 08 прошли те же скрипты с `--config.verify-deps-before-run=ignore` на установленных зависимостях. Пройдено 143 теста в 21 наборе. Флаг отключил автоматический запуск установки при недоступном DNS реестра. Зависимости и lock-файл сохранены.
- Схемы Alpha 07, Alpha 06, Alpha 05 и более ранние проверены фикстурами. Снимок 11 получен запуском оригинального кода Alpha 07 с активным рынком, оплаченным опытом и открытой Долиной. Сравниваются прежние поля, исторические стоимости и RNG.
- Проверены нулевой урожай, уборка со старым ID, автоматическая очистка и посадка, заказ с атомарным списанием, запас генетических линий, достижимость Legendary и 60 сочетаний, повторная выдача и остановка при полном складе.
- Три чистых прохода до 12/12, 16/16, восстановления моста и первого сбора в Долине завершены командами модели. Отдельная сравнительная серия заняла 130–135 активных минут в Alpha 08. Эти минуты отражают симуляцию. [Методика и численные результаты](ALPHA08_BALANCE.md)

## Воспроизведение

```sh
pnpm typecheck
pnpm test
pnpm build
node tools/simulate-alpha08.mjs .
```

Распакуйте ZIP и выполните из него `node serve-playtest.mjs 4302 --loopback`. Чтобы повторить браузерный прогон, запустите чистый Chrome с локальным портом DevTools 9428 и выполните из репозитория команды ниже.

```sh
node tools/playtest-alpha08.mjs http://127.0.0.1:4302 desktop
node tools/playtest-alpha08.mjs http://127.0.0.1:4302 mobile
```

## Ограничения

Vite выдаёт предупреждение о чанке Phaser. Основной JS занимает 1 754,84 kB, 433,11 kB gzip. Полный маршрут острова пройден командами модели. Физический телефон и независимые игроки остаются за пределами этой проверки. Полноценное двухчасовое прохождение через интерфейс, пользовательский темп и долю пассивного дохода предстоит измерить в следующем плейтесте. [Сценарий плейтеста](ALPHA08_PLAYTEST.md)

Открытые задачи UX. Выбор точного количества по партии выполняется в инвентаре, доступном с рынка. Повтор обучения включается в настройках. Отдельный справочник пройденных подсказок и расширенное оформление открытий каждого тира остаются задачами визуальной полировки.
