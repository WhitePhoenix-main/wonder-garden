## Исходная и финальная сборки

Для чистой Alpha 06 выполнены typecheck, 116 тестов и build. Для Alpha 07 выполнены `pnpm typecheck`, `pnpm test` и `pnpm build`. Прошли **129 тестов в 19 файлах**. Повторная сборка дала те же ассеты. Vite сообщает о JS-чанке больше 500 kB. Размер JS составил 1 715,44 kB до gzip и 420,30 kB после. Первоначальный вызов pnpm из ограниченной сети не смог проверить реестр. Проверки с установленными версиями и финальный стандартный запуск прошли.

## Модель и сохранения

- Чистые маршруты на seed 17, 42 и 2026 достигли 12 видов и 16 грядок Зелёного острова за 3 157–3 280 активных секунд. Мост и контрольный сбор в Долине достигнуты за 3 739–3 790 секунд. В этой стратегии первый урожай созрел через 6 секунд, первый гибрид получен через 42 секунды.
- В отдельном подготовленном саду все 60 сочетаний получены через оплаченные опыты, выдачу и посадку. В начале были средства, открытые рецепты, грядки и обычные семена. Снимок с заполненной коллекцией прошёл проверку загрузки.
- Старые фикстуры и снимок Alpha 06 прошли миграцию. Снимок схемы 10 создан кодом исходного коммита из сада Alpha 05 с активной поставкой и текущим опытом. Сравнение старых полей проверяет весь снимок, включая RNG, жизни, профили, лоты, рынок, таймеры, награды и коллекцию. Есть проверки повреждения, backup и будущей версии.
- Для схемы 11 проверены сохранение неудачной серии, две последовательные оплаты в параллельных слотах, отсутствие спойлера, точное клонирование, блокировка источника во время операции и отклонение повторной выдачи. Жест и автосбор сохраняют ценную последнюю жизнь.
- Проверены порог продажи плодов и семян, вынужденная продажа доступных плодов, резервы профиля и вида, сохранение товаров под заказ, выгода по списываемым лотам, стабильная награда и атомарность массовых команд. Отклонённая операция сохраняет и ресурсы, и статистику.

## Воспроизведение

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
node tools/simulate-alpha07.mjs all
node tools/simulate-alpha07-breeding.mjs
```

Для браузерной проверки запустите сервер из ZIP и отдельный Chrome с чистым профилем и локальным портом отладки. Укажите этот порт через `WONDER_TEST_CHROME_PORT`. Для desktop и mobile используйте независимые профили, поскольку начальный сценарий проверяет пустое сохранение.

```sh
node tools/playtest-browser.mjs http://127.0.0.1:4297 desktop all
node tools/playtest-browser.mjs http://127.0.0.1:4297 mobile all
node tools/playtest-alpha07.mjs http://127.0.0.1:4297
```

## Ограничения и открытые задачи

Физический телефон и независимые игроки в проверках не участвовали. В узкой шапке 360×800 название острова может переноситься внутри слова. Непрерывная монокультура в позднем саду всё ещё проводит около 91% времени у нижней цены. Увеличение ёмкости лавки до 150% дало около 0,6 монеты в минуту и не вошло в релиз. Подготовленные Rare-линии и поздний сад имеют начальные капитальные преимущества, указанные в экономическом отчёте.

Для следующей итерации измерить на физических телефонах удобство жестов, понимание разницы между выручкой и денежным потоком, причину ожидания автопродажи и добровольное продолжение после 15 минут. Использовать эти наблюдения при выборе следующих изменений баланса. Публикация на игровых площадках в эту приёмку не входит.
